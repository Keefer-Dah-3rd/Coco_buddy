# Codebase cleanup, 2026-11-04

An audit and cleanup of the Blue Skies fork (branch `feature/blue-skies-panel-live`): dead
code out, repeated logic shared, stale words fixed, every feature kept. Committed as one change, so it
can be reviewed as one diff: 81 files, 485 lines added, 6,724 removed (5,883 of them the retired
design experiments). Swift in the app and package went from 34,661 lines to 28,624.

## Repeated logic simplified

- **Durations and clocks.** Five copies of "25m / 1h 30m" and the mm:ss countdown
  (`TodayView.duration`, `AppModel.clock`, `AssistantPrompt.length`, `TaskFormView.spoken`,
  `RelativeTiming`'s fragments) are one `DurationText`, used at 20+ call sites.
- **Fixed-locale date formatting.** Four identical `en_US_POSIX` formatter set-ups are
  `DateFormatter.fixed`.
- **Service date parsing.** Four RFC 3339 parsers and two `YYYY-MM-DD` parsers are `DateText`.
- **Cards.** Twelve hand-rolled fill + rim modifier chains use one generalised `skyCard`
  (`fill:`, `rim:`, `radius:`, `style:`); the default is still the white hairline card.
- **Meeting heads-up.** The "starts in 17m, before this session would end" line under Today's
  focus banner and on the Focus tab is one `MeetingHeadsUp` view. Today's copy now uses the
  Focus tab's 11 pt style (it was 10.5 pt); the only intentional pixel change.
- **Parent-task menu.** The editor's "Under" menu and the form's parent picker share
  `ParentTaskMenuItems` and `TaskStore.parentCandidates(excluding:)`.
- **Segmented controls.** `SkySegment` and `KeySegment` share `SegmentItem`.
- **Hex colours.** `Color(hex: String)` replaces two inline `#RRGGBB` parsers.
- **HTTP.** One `HTTP.makeSession(timeout:cookies:)` for the three ephemeral sessions;
  `fetch` and `send` share the transport step.
- **Smoothstep.** One function in BuddyCharacter instead of twins in `Dash` and the animator.
- **Priority names.** `TaskPriority(name:)` replaces the hand-written switch in the assistant tools.
- `AppModel.inMeeting` uses `DaySchedule.current(at:)`; `BannerProgress.remainingLabel` uses
  `remaining`; `TaskRow.meta` tests `hasMeta` and shows the "Focused" kicker directly.

## Bugs and open questions found

1. **A focus session that ends while the app is closed is announced nowhere.** It only ever
   set the panel speech line, which the redesign dropped; behaviour is unchanged by this
   cleanup, but a bubble at launch may be wanted.
2. `--banner-selftest` and `--focus-length-selftest` keep the app running afterwards, and a
   Debug launch then terminates any other running Coco (`SingleInstance`). Run them only when
   the Xcode instance isn't up.
3. Day-part boundaries differ by feature: `BannerClock` 5/11/17/21, greetings 5/12/17/22,
   `Dialogue` late night before 6, `BannerComments` before 5. Possibly intentional.
4. `DurationText.spoken(90)` says "1 hours" (pre-existing; only the preset lengths reach it).
5. `--calendar-selftest` leaves a fake Google client ID in an unsandboxed build's defaults
   (pre-existing).
6. `--snapshots` reads the throwaway `DesktopBuddy.preview` defaults suite, which the
   self-tests also write to, so the focus length in the panel renders depends on whatever ran
   last (35 min here before the self-tests, 25 after). The renderer could pin it.

## Left alone on purpose

- The `Theme` / `TypeStyle` / `KeyButtonStyle` / `MonoLabel` system: Settings keeps that look
  by decision, and the speech bubble and LCD chip use it.
- Unused generated tokens (`Space.xxxs/xxxl`, `Sky.dusk/duskDisc/peach`, `Sky.Radius.pill`,
  seven `TypeStyle` presets, `SkyType.displayWins/displayTitle/bodyTiny`,
  `BrandPalette.furShade`): generated from `design/tokens.json`; prune there and in Figma, then
  regenerate.
- Tests-only model API kept as documentation of the models: `BallFlight.impacts`/`landTime`,
  `Dash.velocity`, `Dialogue.offVoice`, `ICalendar.Feed.producer`, `WeatherSnapshot.observedAt`,
  `LinkedEvent.sourceKey`, and `SceneNode`'s SVG export (used by the port tests and the Figma
  snapshot tool).
- Saved-schema fields with no reader (`CalendarEvent.htmlLink`, `occurrenceStart`, `seriesID`,
  `endIsEstimated`; `FocusSessionRecord.taskID`, `finished`; `ICalendar.Event.Status.tentative`).

## Recommendations, not done

- `GoogleCalendarService` and `AppleCalendarService` each keep a week cache with the same
  shape (`weekStart`, one fetch per week, loading set, per-week problems). A shared `WeekCache`
  would remove ~80 lines but is a real refactor of the calendar layer.
- `AppModel` (1,500 lines): the chat-calendar section could become `AppModel+Calendar.swift`
  if `eventRequests` loosens from `private(set)`.
- About 40 `public` BuddyKit members are only used inside the package and could be `internal`.
- `DaySchedule`, `EventDraft`, `EventSource` and `EventChanges` are provider-neutral but live
  in `GoogleCalendar.swift`.
